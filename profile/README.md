# Concentric Circles MRTT Codespace

**仝心圆 / MRTT · 工业数据 AI 代码组织**

本组织汇集 仝心圆 产品研发、工程重建 Skill、NeuBE 开源基座以及相关研究与评测代码。我们专注一件核心的事：**把沉睡在扫描图、PDF、DWG 与 DXF 里的工程知识，转化为可核验、可追溯、可编辑，并能被 CAD、PLM、数字孪生和 AI 系统直接使用的工程上下文。**

## 产品定位

仝心圆是一款工程数据编译产品，围绕「唤醒每一张工程图纸里的数据价值」展开，重点解决三个问题：

- **多源图纸接入**：接收扫描图、PDF、DWG、DXF 等存量资料，保留文件、版本与原始位置。
- **工程信息编译**：读取图纸标注、尺寸与构件关系，并与物料表等工程资料交叉核验。
- **可信结果交付**：由工程 Agent Harness 编排专业 Skills、工具与验证流程，输出可验证并能进入 CAD、PLM、数字孪生和 AI 系统的工程上下文。

当前首个垂直场景为**电力铁塔图纸**：从结构复杂、标准严格的工程图纸开始，把 AI 读图、数据编译和三维重构做深，再走向更多工业场景。
